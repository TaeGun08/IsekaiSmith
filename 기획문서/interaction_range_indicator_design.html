상호작용 범위 표시(발판) 기획서

interaction_range_indicator_design.html · 신규

사용자 피드백: "현재 상호작용 하는 보관함, 판매테이블, 용광로 아래에 검은색 발판 UI 같은 느낌... 이 정도 근처에 오면 상호작용이 가능하다는 느낌". 참고로 넣어주신 이미지(모바일 타이쿤류 - 워크 스테이션 캐릭터 발밑에 점선 원형 표시)처럼, 실제 상호작용 판정 반경을 그대로 바닥에 시각화하는 플레이스홀더 마크를 추가합니다.

1. 범위

적용 대상

  • 대장간(용광로/모루) - CraftingStation
  • 보관함 2개(나무/광물 크레이트) - StorageDepot
  • 판매대 - OrderQueueManager

제외

  • 벌목장/채석장 - 사용자 지정 제외("벌목장이랑 채석장엔 필요 없어"). 나무/광물은 런타임에 흩뿌려지는 개별 노드라 "여기 오면 채집 가능"이 아니라 나무 하나하나에 붙는 감각이라 발판과 안 맞음

2. 비주얼 v2 - 개정

v1의 납작한 Cylinder 프리미티브 대신, 참고 이미지처럼 점선 원형(대시 링)으로 개정 - 사용자 피드백("실린더보단 이미지를 쓰거나 UI로 그렸으면"). 새 텍스처 에셋을 임포트하는 대신, 이 프로젝트가 이미 쓰던 런타임 스프라이트 생성 방식(UIShapes.Circle() - 조이스틱/단조 미니게임 다이얼에 사용 중)을 그대로 확장한 UIShapes.Ring()으로 대시 링을 코드로 생성.

2-1. 활성화 피드백 v2 - 신규

사용자 피드백: "플레이어가 밟으면 살짝 활성화 되는 색상이 바뀌고 살짝 넓어지는 듯한 느낌". 평소엔 어두운 톤(idleColor)이다가, 플레이어가 반경 안에 들어오면 대장간 골드 포인트 컬러(activeColor)로 서서히 바뀌면서 살짝(1.12배) 커짐 - 두 값 모두 즉시 스냅이 아니라 Color.Lerp/Mathf.Lerp로 부드럽게 보간(초당 8배속, 이 프로젝트의 다른 펄스 애니메이션과 비슷한 속도감).

3. 크기 - 실제 판정 반경과 100% 일치

대장간CraftingStation.interactRadius = 2.5 그대로 읽어와서 지름 5m 원 생성
보관함(나무/광물 각각)StorageDepot.depositRadius = 2 그대로 읽어와서 지름 4m 원 생성
판매대OrderQueueManager.interactRadius = 2.5 그대로 읽어와서 지름 5m 원 생성

눈대중 배치가 아니라, 각 클래스가 이미 갖고 있던 판정 반경 필드를 그대로 재사용 - 나중에 반경 값이 바뀌어도 발판이 따로 안 어긋남(GuidedTutorial의 화살표 숨김 반경도 동일한 필드를 재사용하도록 같이 맞춤, §5 참고).

4. 구현 메모 구현 완료

InteractionPadIndicator(Assets/01. Scripts/Environment/, v1의 InteractionPadVisual 정적 헬퍼를 대체) - World Space Canvas + Image로 구성, Customer 말풍선/CustomerVisualManager의 러시아워 라벨과 동일한 "코드로 캔버스를 직접 만들어 바닥에 눕히는" 관례. 활성화 피드백(색/크기 보간)이 매 프레임 필요해서 이번엔 정적 헬퍼가 아니라 작은 MonoBehaviour로 전환했지만, 진입점은 여전히 Attach(Transform parent, float radius) 한 줄 호출로 유지(모듈화 원칙 - 반경을 두 곳에 들고 있지 않음).

  • CraftingStation.Awake(), StorageDepot.Awake(), OrderQueueManager.Awake() 각각에서 한 줄 호출.
  • 캔버스를 Quaternion.Euler(90, 0, 0)으로 눕혀 바닥에서 위를 보게 배치, raycastTarget = false로 이동/클릭을 막지 않음.
  • 매 프레임 플레이어와의 거리를 자체적으로 재서 활성화 여부 판정 - 각 클래스의 PlayerNear/nearPlayer 필드에 의존하지 않아 결합도 낮음.

5. 부가 효과 - 가이드 튜토리얼 화살표 숨김 반경과 통일

같은 사용자 피드백에서 함께 나온 "화살표는 목표에 가까워지면 비활성화" 요청도 이 세 클래스의 반경 필드를 공개 프로퍼티(InteractRadius/DepositRadius)로 열어서 GuidedTutorial이 그대로 읽어가도록 처리 - 발판이 보이기 시작하는 지점과 화살표가 사라지는 지점이 항상 정확히 같은 원. 자세한 내용은 guided_tutorial_design.html §9 참고.
