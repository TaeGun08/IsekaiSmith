스테이지 시스템(해금 게이트) 기획서 v1

stage_system_design_v1.html · 신규 - 로드맵 ③, game_design_doc.html §2/§7을 구현 가능한 1단계로 구체화. "일단 로드맵 위주로 진행" 지시 반영.

§7 원문의 3단계(필드→스테이지→던전) 중 스테이지만 이번 범위로 잡습니다. 던전(랜덤 생성 지형)은 그 자체로 새 맵/지형이 필요해 "맵 디자인은 직접 하신다"는 원칙과 맞물리는 큰 작업이라 다음 단계로 미룹니다. 대신 스테이지는 기존 필드 사냥터에 있는 게이트 하나에서 웨이브 전투로 여는 방식으로 설계해서 새 지형 없이도 "해금 게이트"의 핵심 - 스테이지 클리어 → 광물/마석 등급 상승 + 필드 몬스터 강화 + 다음 스테이지 개방 - 을 실제로 동작하게 만드는 게 목표입니다.

1. 이번 범위

이번에 포함

  • 스테이지 3개(§10 결정사항 "우선 소수(예 3개)") - 순차 해금
  • 필드에 이미 있는 사냥터 근처에 "스테이지 게이트" 1개 - 좌표는 FieldMonsterSpawner가 쓰는 것과 같은 파생 방식(기존 벌목장/채석장/카운터 위치 기준 계산)이라 새로 찍는 좌표 없음
  • 게이트 상호작용 → 웨이브 전투(스테이지당 2웨이브, 뒷웨이브가 더 강함) → 클리어 시 보상
  • 클리어 보상: 마석 획득 + 다음 스테이지 해금 + OreBank/ManaBank 등급 상한(Ceiling) 즉시 상승 - OreBank.cs 주석에 이미 적혀 있던 "로드맵③ 생기면 이 조건을 던전(스테이지) 클리어 플래그로 교체" 그 자리를 채움
  • 필드 잡몹도 클리어한 스테이지 수만큼 조금씩 강해짐(§7 "필드 몬스터도 동반 강화")

다음 단계로 미룸

  • 던전(랜덤 생성 지형, 광맥 심화, 보스 처치 시 동굴 개방) - 새 맵/지형 필요, 로드맵③의 나머지 절반
  • 속성별 마석(지금은 필드 드랍과 동일하게 "등급만 있고 속성은 랜덤 굴림") - 실제 구분 지어 주려면 ManaBank 자체에 속성 축 추가가 필요해서 범위 밖
  • 숙련 모험가/VIP 손님 등급 - OrderQueueManager 쪽 확장이 필요해서 별도 작업
  • 스테이지 전용 몬스터 비주얼(지금 슬라임과 다른 모양) - 색만 다르게, 모양은 재사용

2. 데이터 모델

StageBank신규 정적 클래스, OreBank/ManaBank과 같은 파일 스타일. HighestStageCleared (0=아직 없음) 하나만 들고 있음. IsUnlocked(int stage) = stage <= HighestStageCleared + 1 (다음 스테이지까지는 항상 도전 가능).
OreBank.Ceiling / ManaBank.Ceiling기존 누적 예치량 조건과 스테이지 클리어 조건 중 더 높은 쪽을 사용(둘 다 유지 - 먼저 파밍한 사람이 손해 안 봄). 스테이지 1/2/3 클리어가 각각 Steel/Mithril/Orichalcum, Common/Refined/Greater를 즉시 연다.
MonsterSpawn()에 hpMultiplier/ damageMultiplier 파라미터 추가(기본값 1 - 기존 필드 슬라임 동작 그대로). 스테이지 웨이브 몬스터와, 스테이지 클리어 수에 비례해 강해지는 필드 몬스터 둘 다 이걸로 표현.
StageGate신규 MonoBehaviour - CraftingStation/ StorageDepot과 같은 "근접 시 InteractionPromptUI 표시" 패턴. 잠긴 스테이지는 프롬프트에 "Locked - Clear Stage N first" 표시, 상호작용 버튼 비활성.
StageEncounterController신규 - 게이트 상호작용 시 웨이브 스폰/진행/클리어 판정을 맡음. 진행 중엔 필드 몬스터와 별개로 취급(필드 잡몹 파밍과 안 섞임).
StageEncounterUI신규, 작은 HUD - "STAGE 2 - Wave 1/2, 3 remaining" 정도만 표시, 인카운터 진행 중에만 보임.

3. 난이도 곡선

스테이지 1웨이브1: 슬라임x3(HPx1.3/DMGx1.2), 웨이브2: 슬라임x2 + 엘리트x1(HPx2.2/DMGx1.6)
스테이지 2웨이브1: 슬라임x4(HPx1.8/DMGx1.5), 웨이브2: 슬라임x3 + 엘리트x1(HPx3/DMGx2)
스테이지 3웨이브1: 슬라임x5(HPx2.4/DMGx1.8), 웨이브2: 슬라임x3 + 엘리트x1(HPx4/DMGx2.5)
필드 잡몹HP/DMG 배율 = 1 + 0.25 × StageBank.HighestStageCleared (스테이지 3까지 다 깨면 필드도 최대 1.75배)

엘리트는 별도 몬스터 종류가 아니라 Monster 배율만 크게 준 것 - 색을 더 진하게 틴트해서 구분(새 메시 없음, 도끼/망치/단검 스윙 재사용 때와 같은 방식).

4. 흐름

게이트 근접 → 프롬프트("Enter Stage N") → 확인 시 웨이브1 스폰(필드 잡몹과 별개 인스턴스) → 전부 처치 → 웨이브2 스폰 → 전부 처치 → 클리어: 마석 보상 지급 + StageBank.HighestStageCleared 갱신 + 결과 표시 → 다음 스테이지 게이트가 잠금 해제. 웨이브 도중 플레이어가 죽거나 게이트에서 너무 멀어지면 인카운터 취소(몬스터 정리, 보상 없음, 재도전 가능).
