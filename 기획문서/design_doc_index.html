기획서를 파일 하나에 다 합치지 않고, 이 목차 하나에서 컨텐츠별 세부 문서로 갈라지는 구조로 정리했습니다. 각 문서는 지금도 실제로 만들어지고 있는 시스템의 기준 문서라 계속 개별 파일로 남겨두는 편이 관리하기 쉽습니다 (한 파일에 전부 합치면 편집할 때마다 무관한 시스템까지 다 뒤져야 함). 대신 이 페이지가 "지금 뭐가 있고, 뭐가 최신본이고, 뭐가 지금도 코드에서 실제로 참조되는지"를 한눈에 보여주는 입구 역할을 합니다. 최신/현재은 지금 코드가 그대로 따르는 기준 문서, 일부 참조는 구버전이지만 특정 섹션이 아직도 다른 문서/코드에서 인용되어 남겨둔 것, 개발 도구는 게임 내용이 아닌 제작 과정용 문서입니다.
