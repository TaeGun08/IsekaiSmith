이세계 대장장이 - 플레이 가이드

현재 빌드 기준 조작법 & 진행 흐름 안내 (모바일 터치 / PC 마우스 공용)

이 문서는 지금 실제로 플레이할 수 있는 기능만을 기준으로 작성되었습니다. 각 섹션 옆에는 구현됨 / 준비중 표시가 붙어 있어서, 지금 바로 해볼 수 있는 것과 앞으로 추가될 것을 구분할 수 있습니다.

1. 기본 조작 구현됨

1
이동 - 가상 조이스틱

화면 아무 곳이나 터치(또는 마우스 클릭)하고 드래그하면 그 지점에 조이스틱이 나타나고, 캐릭터가 드래그 방향으로 이동합니다. 손을 떼면 조이스틱이 사라집니다.

2
자동 정면 응시

이동하지 않고 제자리에 있을 때는 캐릭터가 자동으로 채집 대상(나무/광석)을 바라봅니다.

키보드 단축키는 사용하지 않습니다. 모든 조작은 터치/클릭 기반이라 모바일 출시를 염두에 두고 설계되어 있습니다.

화면을 터치&드래그 → 가상 조이스틱으로 이동

2. 채집 - 벌목 & 채굴 구현됨

1
나무 / 광석 근처로 이동

맵에 배치된 나무(벌목장)나 광석(채석장)에 캐릭터가 가까이 다가가면 자동으로 채집이 시작됩니다. 별도의 버튼 입력은 필요 없습니다.

2
일정 간격으로 자동 타격

도끼/곡괭이를 자동으로 휘두르며 일정 횟수를 타격하면 나무가 쓰러지거나 광석이 깨지며 재료(목재/광물)를 드랍합니다. 타격할수록 대상에 손상 표시(색 변화)가 누적됩니다.

3
재료는 등에 쌓임

획득한 재료는 캐릭터 등 뒤에 쌓이는 연출로 표시됩니다(목재/광물 각각 최대 8개까지 소지). 이동 시 좌우로 살짝 흔들리는 연출이 있습니다.

4
다 채집한 자원은 잠시 후 리스폰

나무는 약 6초, 광석은 약 4초 후 다시 자라나거나 생성됩니다. 나무는 원래 위치 근처 랜덤한 곳에서 다시 자랍니다.

3. 보관함에 예치하기 구현됨

1
목재 보관함 / 광물 보관함으로 이동

대장간 근처에 목재 전용 보관함과 광물 전용 보관함이 따로 배치되어 있습니다. 각 보관함은 해당하는 재료만 받습니다.

2
가까이 서 있으면 자동 예치

보관함 근처에 서 있으면 등에 쌓인 재료가 날아가는 연출과 함께 자동으로 보관되고, 화면 우측 상단 자원 HUD 수치가 올라갑니다.

Wood 12
Ore 7
Mana 0
Tool 0
우측 상단 HUD: Wood / Ore / Mana / Tool 보유량

4. 제작 - 대장간 구현됨

용광로와 모루가 하나로 붙어있는 대장간 작업대 하나에서 재료 선택부터 제련, 단조까지 이어서 진행합니다. 재료가 충분한 상태로 대장간 근처에 서면 CRAFT / QUICK CRAFT 두 개의 버튼이 뜹니다.

버튼동작
CRAFT재료 선택 → 제련 미니게임 → 단조 미니게임을 순서대로 거쳐 제작합니다. 미니게임 결과에 따라 완성품 개수(추가 보너스)가 달라집니다.
QUICK CRAFT미니게임을 모두 건너뛰고 즉시 평균 품질(50%)로 제작합니다. 빠르게 재료를 소모하고 싶을 때 사용합니다.

현재 레시피: 광물 2개 + 목재 1개(+마석 선택) → 완제품(Tool) 1개. 판매 가능한 아이템 종류가 늘어나면 레시피도 확장될 예정입니다.

4-2. 제련 - 용광로 (클릭 펌프질)

1
화면을 탭(클릭)해서 풀무질

탭할 때마다 온도 게이지가 올라갑니다. 가만히 있으면 온도가 서서히 식습니다.

2
초록색 적정 구간 유지

온도가 초록 구간(적정 범위) 안에 머문 시간이 길수록 품질이 올라갑니다.

3
과열 주의

적정 구간을 넘어 너무 뜨겁게 만들면(빨간 구간) 과열 페널티가 붙어 오히려 품질이 깎입니다.

4-3. 단조 - 모루 (랜덤 위치 + 파워 게이지)

Target 59%
HOLD, RELEASE ON TARGET
홀드로 게이지 충전 → 목표 %에 최대한 가깝게 릴리즈
1
매 라운드마다 칼날 위 랜덤 위치 + 목표 % 등장

노란 점(타격 위치)이 칼날 위 랜덤한 곳에 나타나고, 상단에 목표 퍼센트(예: "Target 59%")가 표시됩니다.

2
버튼을 꾹 눌러 파워 게이지 충전

누르고 있는 동안 세로 게이지가 0%→100%까지 차오릅니다.

3
목표 %에 최대한 가깝게 손을 떼기

목표와의 오차가 ±1% 이내면 Perfect, ±5% 이내면 Good, 그 밖이면 Miss로 판정됩니다. 총 4라운드를 진행하며, 평균 판정이 최종 단조 품질이 됩니다.

제련 품질과 단조 품질의 평균이 최종 제작 품질이 됩니다. 품질이 높을수록 완성품이 추가로 1개 더 나올 확률/확정 보너스가 붙습니다.

6. 아직 준비중인 콘텐츠 준비중

기획서(game_design_doc.html) 기준으로 아래 시스템들은 아직 코드로 구현되지 않았습니다. 완제품(Tool)을 만들어도 현재는 팔거나 사용할 곳이 없고, 마석(Mana)은 아직 얻을 방법이 없어 항상 0으로 표시됩니다.

콘텐츠내용
손님 / 판매 시스템완제품을 손님 주문에 맞춰 판매하고 돈을 버는 시스템. 아직 없음.
필드 사냥기본 재료를 얻는 상시 개방 필드 전투. 아직 없음 (현재는 몬스터 없이 채집만 가능).
스테이지 사냥마석을 얻는 웨이브 전투 콘텐츠. 아직 없음 - 이 때문에 마석(Mana)이 항상 0.
던전클리어 시 채석장 광물 등급을 업그레이드하는 랜덤 생성 던전. 아직 없음.
암시장 상인확률적으로 방문해 희귀 재료를 비싸게 팔고, 보유 재료를 급전으로 매입해주는 NPC. 아직 없음.
평판 시스템주문 실패 시 이후 판매 수익 %가 줄어드는 페널티. 판매 시스템이 먼저 필요해 아직 없음.
다양한 무기 실루엣현재는 검(Sword) 실루엣만 구현. 도끼/망치/단검 등은 추후 추가 예정.
플레이어 전투직접 만든 무기를 들고 싸우는 전투 액션. 아직 없음.
