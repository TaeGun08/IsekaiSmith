임시 튜토리얼 기획서

tutorial_design.html · 채집→제작→판매 루프가 갖춰진 지금 시점 기준, 시퀀스/구성/조작법만 알려주는 가벼운 온보딩

지금까지 만든 시스템(이동, 채집, 대장간 제작, 판매 카운터)을 처음 켰을 때 순서대로 훑어주는 텍스트 슬라이드형 튜토리얼입니다. 손님 캐릭터나 맵 연출처럼 나중에 바뀔 여지가 큰 부분에 맞추기보다, 지금 실제로 돌아가는 조작/흐름을 정확히 안내하는 데 집중합니다 - 나중에 시스템이 바뀌면 슬라이드 텍스트만 교체하면 되도록 로직과 콘텐츠(슬라이드 데이터)를 분리합니다.

1. 범위

이번에 포함

  • 풀스크린 슬라이드 오버레이(제목+짧은 설명, 다음/건너뛰기)
  • 슬라이드 5장: 환영 → 이동 → 채집 → 제작 → 판매
  • 최초 1회 자동 표시(이후 PlayerPrefs로 기억), 우측 상단 "?" 버튼으로 재열람
  • 실제 조작(드래그 이동/자동 채집/CRAFT 버튼/주문서 탭)과 일치하는 문구

이번엔 미룸

  • 특정 행동을 실제로 수행해야 다음 슬라이드로 넘어가는 "가이드형" 튜토리얼(하이라이트/화살표 연출 포함) - 지금은 그냥 읽고 넘기는 슬라이드까지만
  • 보스전/사냥터 등 아직 없는 시스템 안내
  • 다국어 대응 - 지금 프로젝트 텍스트가 전부 한글이라 이 문서도 한글만

2. 슬라이드 5장 - 실제 구현 기준

1. 환영이세계 대장장이 소개 한 줄 + "화면을 넘겨서 플레이 방법을 확인하세요"
2. 이동화면 아무 곳이나 드래그하면 그 방향으로 이동합니다 (FloatingJoystick - 가상 조이스틱이 드래그 시작 위치에 나타남).
3. 채집벌목장의 나무 / 채석장의 돌에 가까이 다가가면 자동으로 채집됩니다 (PlayerMining/PlayerWoodcutting - 버튼 없음). 짊어진 재료는 근처 보관함에 다가가면 자동으로 저장됩니다(StorageDepot).
4. 제작대장간에 재료(나무+돌)가 충분한 채로 다가가면 CRAFT(정밀 제작 - 배치/제련/단조 미니게임) 또는 QUICK CRAFT(즉시 제작) 버튼이 뜹니다 (InteractionPromptUI). 완성된 도구는 품질에 따라 Rough~Legendary 등급이 매겨집니다.
5. 판매판매대에 다가가면 손님 주문서가 뜹니다. 주문서를 탭하면 조건에 맞는 등급의 도구가 있을 때 자동으로 납품하고 골드를 받습니다(SalesCounterUI). 제때 못 받으면 평판이 조금 깎입니다 - 채집→제작→판매를 반복해서 골드를 모으는 게 지금까지의 핵심 루프입니다.

4. 구현 메모

  • 슬라이드 데이터 - 제목/설명 문자열 배열로 분리해서 하드코딩 UI 빌드 로직과 콘텐츠를 섞지 않습니다(시스템이 바뀌면 배열만 수정).
  • 재열람 버튼 - 기존 HUD 어딘가에 작게 "?" 버튼을 추가. 첫 실행 자동 표시 여부는 PlayerPrefs.GetInt("TutorialSeen")로 판정.
  • 다른 UI와의 우선순위 - 판매/제작 프롬프트보다 위에 떠야 하므로 sortingOrder를 가장 높게(50) 설정.
