던전 기획서 v2

dungeon_design_v2.html · dungeon_design_v1.html(3차 정정으로 누적) 대체 - 로드맵③ 나머지 절반, game_design_doc.html §2/§7. 여러 차례 정정을 거친 최종 형태를 한 번에 정리.

던전은 별도 씬(원형 아레나) + 데이터 시트 기반 다층 구조 + 반복 가능한 깊이 도전으로 정착. 스테이지(1회성, 고정 3개)와 달리 던전은 몇 번이든 다시 들어가 더 깊이 도전할 수 있는 콘텐츠 - 최고 기록(DungeonBank.DeepestFloorCleared)만 영구 저장되고, 그 기록에 비례해 채석장 품질이 서서히 좋아진다.

1. 개방/진입

DungeonBankIsUnlocked = StageBank.AllStagesCleared(스테이지 3개 클리어 = 던전 개방, 영구). 매번 1층부터 시작해서 갈 수 있는 만큼 내려감 - DeepestFloorCleared(최고 기록)만 누적 저장, 죽거나 후퇴해도 이미 깬 층의 기록은 안 사라짐.
진입점StageSelectUI 4번째 카드 - 항상 "TAP TO ENTER"(또는 "Deepest: Floor N - TAP TO DIVE AGAIN"), 스테이지처럼 잠기지 않음.

2. 전투 구성 - 별도 씬 + 사방 포위 + 층별 보스

DungeonSceneStageScene과 완전히 별도 파일 - DungeonSceneController가 애디티브 로드/언로드 전담. 원형 바닥(Cylinder) 하나만 코드로 생성, 매 방문 위치 무작위.
DungeonEncounterController웨이브가 라인 한쪽 끝이 아니라 플레이어(아레나 중심) 주위 360도 균등 스폰 - 사방에서 접근. 모든 층이 몹 무리 → 그 층 전용 보스 구조: 몹 전멸 시 보스 1마리 등장(더 크고 진한 빨강 - 신규 Monster.SetScale), 보스 처치 시 다음 층 자동 진행. 층이 깊어질수록 몹/보스 전부 강해짐.

3. 데이터 시트 신규

사용자 요청: "던전을 최대한 많이 만들어도 좋아. 데이터 시트를 이용해서 미리 던전 정보를 불러와서 사용하는 식, 스테이지도 마찬가지로." 하드코딩 배열 대신 ScriptableObject 데이터 시트로 전환 - 층/웨이브 추가·조정이 코드 수정 없이 인스펙터 편집만으로 가능.

DungeonFloorTable Assets/05. Data/Resources/DungeonFloorTable.asset - 행마다 몹 수/몹 HP·공격력 배율/보스 HP·공격력 배율. 기본 15층 수록(공비 성장 공식으로 산출), 필요하면 인스펙터에서 행 추가만 하면 됨. 에셋을 못 찾으면 기존 3층 하드코딩 표로 대체(안전장치).
StageWaveTableAssets/05. Data/Resources/StageWaveTable.asset - 스테이지 3개×웨이브 2개(기존 수치 그대로 이관). 행마다 스테이지 번호+웨이브 순번을 갖고 있어서 한 테이블에 전 스테이지가 같이 들어감.
런타임 로딩Resources.Load<T>() - 두 컨트롤러 다 코드 전용 싱글턴(씬에 없음)이라 인스펙터에 직접 드래그할 자리가 없어서, Resources 폴더 경로로 로드하는 방식 채택.

4. 채석장 품질 곡선 신규

사용자 요청: "던전을 클리어하면 점점 높은 등급의 광석이 뜰 확률이 올라가도록... 초반엔 0퍼로 맞추고 최대한 깊게 내려갈수록 퍼센테이지가 조금씩, 던전이 어려워질수록 더 많이 오르도록." 단순 등급 상한 개방(기존)에 더해서, 등급 상한 안에서도 최고 등급이 나올 확률 자체가 깊이에 비례해 올라가는 2중 구조로 구현.

등급 상한OreBank.DungeonCeiling - DeepestFloorCleared 8층 이상이면 오리하르콘까지 개방(그 전까진 스테이지가 미스릴까지만 열어줌).
품질 확률(신규)OreBank.QualityBias = (깊이 비율)² × 0.75 - 제곱 곡선이라 얕은 층에서는 거의 0%에 가깝고, 깊이 15층에 가까워질수록 급격히 올라감("조금씩 → 더 많이"). 이 확률만큼은 광물 채집 시 등급 상한 그 자체가 확정으로 나옴(균등 굴림 대신).

5. 다음 단계로 미룸

진짜 절차적 방/복도 생성(지금은 원형 아레나 반복), 몬스터 종류 다양화(지금은 슬라임 하나, 틴트/스케일로만 구분), VIP/지명 의뢰 손님, 전설 등급 전용 재료 - 전부 이번 예산 밖.
