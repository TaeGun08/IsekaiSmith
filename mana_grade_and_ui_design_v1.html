1. 마석 등급 시스템 - 제안 구조 결정 필요

왜 OreBank 패턴을 그대로 복제하는가

광물은 이미 OreGrade(4단계) + OreBank(등급별 재고 + 누적 채굴량 기반 Ceiling)로 정확히 같은 문제(등급 존재, 필드에서 처음엔 낮은 등급만, 점진적으로 상한 개방)를 풀어놓은 상태입니다. 마석도 완전히 동일한 구조가 필요하므로, 새 개념을 발명하지 않고 같은 패턴을 그대로 복제하는 것을 제안합니다. (검 하나에 올인하지 않고 유동적으로 확장 가능해야 한다는 기존 방향과도 일치 - 이 축은 나중에 다른 소재/자원에도 재사용 가능한 형태로 남습니다.)

등급 5단계 (제안)

등급표시명효과 배율(제안)필드 드랍
0최하급 (Crude)×1.0 (현재 수치 그대로)지금 바로 개방
1하급 (Common)×1.4추후 상한 개방(2단계 목표)
2중급 (Refined)×1.9필드 상한 대상 아님(설계상 미개방)
3상급 (Greater)×2.5미개방(스테이지/던전 전용, 로드맵 ③)
4최상급 (Pristine)×3.2미개방(스테이지/던전 전용)

요청하신 "필드에서는 하급~중하급까지, 일단은 최하급만"을 반영: 필드 상한 게이트는 처음엔 최하급 고정, 나중에 문턱값 하나만 올리면 하급까지 열립니다(OreBank.Ceiling과 동일한 방식 - 던전 시스템이 아직 없어 "누적 채집량" 문턱을 임시 대역으로 사용). 중급 이상은 처음부터 필드가 아닌 스테이지/던전 전용으로 설계해 나중에 로드맵 ③이 붙을 자리를 미리 비워둡니다.

효과 배율은 상태이상 수치(화상/중독 틱 데미지, 번개 기절 시간, 냉기 둔화 지속시간)에 곱해집니다. 최하급 배율을 정확히 ×1.0으로 맞춰서, 지금 튜닝된 수치가 그대로 유지되고 기존 플레이가 깨지지 않습니다.

2. 재료선택 UI 레이아웃 & 가독성 개선안 결정 필요

현재 문제

  • 슬롯 5개(광물·마석×3·목재)가 역할 구분 없이 한 줄에 동일한 간격으로 나열됨 - "필수 재료"와 "선택 인챈트"가 시각적으로 구분되지 않음
  • 슬롯 라벨 글자 크기(20)가 작아 초기 상태("Ore"/"Mana"/"Wood")와 선택 후 상태를 빠르게 구분하기 어려움
  • 크래프트 결과(등급/등급 조합)를 FORGE를 누르기 전에는 전혀 미리 볼 수 없음 - 칼날/손잡이 색조 변화만으로 유추해야 함
  • 시트(재료 목록) 칩 글자 크기(22)도 작은 편

개선안

  1. 슬롯 재배치 + 그룹 구분선: 현재 순서(광물-마석-마석-마석-목재)를 광물·목재(필수)를 왼쪽, 마석×3(선택 인챈트)을 오른쪽으로 재배치하고, 두 그룹 사이에 얇은 구분선 + 그룹 라벨("REQUIRED" / "ENCHANT · OPTIONAL")을 추가합니다.
  2. 슬롯 라벨 확대: 20→24, 굵게. 채워진 슬롯은 테두리를 추가해 미채움과의 대비를 높입니다.
  3. 결과 미리보기 줄 추가: FORGE 버튼 위에 한 줄("Iron Sword" 처럼 현재 슬롯 상태로 만들어질 아이템 이름)을 추가해 누르기 전에 결과를 바로 읽을 수 있게 합니다. (등급/품질은 미니게임 이후 정해지므로 여기엔 소재 조합만 표시)
  4. 시트 칩 글자 확대: 22→26, 보유 개수 표시도 더 굵게.
  5. 힌트 텍스트 대비 강화: 현재 회색(0.75,0.72,0.68)이 어두운 배경과 대비가 약함 - 밝기를 살짝 올림.

구조적 변경(등급/축 추가) 없이 순수 배치·타이포 조정이라 마석 등급 작업과 독립적으로 먼저 진행해도 되고, 같이 진행해도 됩니다. 마석 슬롯을 오른쪽 그룹으로 모아두면 나중에 마석 등급 칩이 늘어나도 레이아웃이 안 깨집니다.

3. 추가로 고려할 만한 것들 (의견)

  • 마석 등급 시각 구분: 인벤토리/시트에서 등급별로 살짝 다른 테두리 색(위 표의 스와치처럼)을 쓰면 나중에 등급이 여러 개 섞였을 때 한눈에 구분됩니다.
  • 필드 상한 문턱값: 광물의 SteelThreshold=60처럼, 마석도 "누적 마석 획득량 N개부터 하급 개방" 식의 숫자가 필요합니다 - 정확한 숫자는 플레이 템포를 보면서 나중에 튜닝하는 걸 권장(우선 하급 개방 없이 시작, 추후 요청 시 문턱값만 추가).
  • 마석 슬롯 3개 각각 다른 원소를 넣을 수 있는 현재 UI이지만 실제로는 ApplyCraft가 소모된 총 개수만 보고 원소 하나를 랜덤으로 굴립니다(3개를 넣어도 결과는 원소 1개). 등급 시스템이 들어가면 "3개를 넣으면 등급도 더 잘 나온다" 같은 규칙을 추가할 수도 있는데, 이번 스코프에는 포함하지 않고 일단 배율은 등급에만 연동하는 걸 제안합니다(범위를 너무 넓히지 않기 위해).
