## KEY PROJECTS 신규 항목

**Tools**: Unity 6, C#, ScriptableObject, Unity Editor MCP

**이세계 대장장이 (IsekaiSmith)**  ·  2026.07 ~ 진행중 (개인 프로젝트, AI 페어 프로그래밍)

- **등급 연동 제작 파이프라인 구축**: 자원 등급별 재고 시스템을 제작소와 연동해, 채집 재료 등급이 곧바로 무기 품질로 반영되는 구조 설계.
- **피자레디식 판매 큐 구현**: 최대 5인 대기줄과 카운터 재고를 관리하는 주문 매니저 설계로, 도착한 손님에게만 요구치를 노출하도록 상태 세분화.
- **3단 전투 루프 및 온보딩 설계**: 필드-스테이지-던전 난이도를 단계적으로 연결하고, 가이드 튜토리얼로 신규 플레이어의 전체 루프 완주 유도.
- **AI 실행·검증 루프 구축**: 작업 로그 기반 세션 인계와 Unity Editor MCP를 통한 AI 직접 실행·콘솔 검증 원칙으로, 90개 스크립트·1.7만 줄 코드베이스를 커밋 단위로 안정 관리.
- **AI 협업 전용 에디터 툴 제작**: Claude/Codex/Cursor 세션을 Unity 에디터 내에서 직접 관리하는 커스텀 툴(AiCompanion)을 IMGUI에서 UI Toolkit으로 직접 리팩토링해 완성.

대장장이가 채집→제작→판매→전투→재투자를 순환하는 3D 캐주얼 RPG. AI를 페어 프로그래머로 두고 90개 스크립트·약 1.7만 줄 규모의 코드베이스를 6주 이상 지속 개발했습니다.

역할: 1인 개발 (기획/프로그래밍 전담) 및 AI 협업 워크플로우 설계
