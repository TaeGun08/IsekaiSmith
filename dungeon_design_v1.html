dungeon_design_v1.html · 신규 - 로드맵 ③ 나머지 절반, game_design_doc.html §2/§7. stage_system_design_v2.html의 레인 전투 인프라를 그대로 재사용.

원안의 "보스 처치 → 동굴 개방", "매 방문 랜덤 생성 방 구조"를 이번 예산 안에서 구현 가능한 형태로 축소: 보스 전투는 스테이지 3 클리어로 대체(신규 보스 시스템 없음), 절차적 방 생성 대신 매 방문마다 위치·길이가 무작위인 레인 전투로 표현. 채석장 광맥 심화(오리하르콘 상한)는 원안대로 던전 최초 클리어 전용으로 되돌림 - 지금은 스테이지가 임시로 대신 열어주고 있던 자리.

1. 개방/재방문

DungeonBank(신규)IsUnlocked = StageBank.AllStagesCleared && !HasClearedOnce. 스테이지와 동일하게 최초 클리어 1회만(사용자 정정: "던전은 최초클리어만 가능하고... 업그레이드가 주 목적이야") - 클리어 즉시 다시 잠김, 재입장/파밍 없음.
진입점StageSelectUI에 4번째 카드로 추가 - 클리어 전까지만 "TAP TO ENTER", 클리어 후엔 스테이지 카드와 동일하게 "CLEARED"로 잠김.

2. 전투 구성

StageEncounterController에 던전 전용 웨이브 4개 추가(스테이지 3웨이브보다 김+강함, 마지막 웨이브가 사실상 보스전). 레인 자체(바닥)는 StageSceneController가 매 방문마다 위치를 무작위로 재계산해서 "새로 생성된 것"처럼 보이게 함(완전한 절차적 방 생성 대신 최소 비용으로 "매번 다르다"는 느낌만 구현).

3. 보상 v1.1 정정

사용자 정정: "던전에서 클리어 했다고 마석을 얻거나 하는 건 없고 업그레이드가 주 목적이야." - 골드/마석 같은 직접 보상 없음. 채석장(광물)만 대상 - 마석 쪽은 이번 던전과 무관하게 그대로 둠.

유일한 보상DungeonBank.MarkClearedOnce() → OreBank Ceiling이 오리하르콘까지 상승(신규 DungeonCeiling - 기존 StageCeiling은 미스릴에서 멈추도록 하향 조정, 원안의 "던전 클리어 전용 상한" 의미를 되살림). ManaBank는 손 안 댐 - 그레이터가 여전히 상한.

4. 다음 단계로 미룸

진짜 절차적 방/복도 생성, 전용 보스 전투 시스템, VIP/지명 의뢰 손님, 전설 등급 전용 재료 - 전부 이번 예산 밖. "컨텐츠와 시퀀스 완성" 목표에 맞춰 최소 구현으로 흐름만 닫는 것이 이번 목표.
